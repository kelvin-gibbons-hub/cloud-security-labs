# Lab 01 - HTTP and DNS Basics

## Objective

Understand how Python and Linux tools interact with DNS, HTTP, and network services.

## Tools Used

-Python
-socket
-requests
-snslookup
-curl
-nmap

## What I Did

1. Resolved a hostname to an IP address using Python.
2. Sent an HTTPS requesst using Python requests.
3. Examined HTTP response header.
4. Queried DNS from the Linux command line.
5. Examined HTTP headers using curl.
6. Performed basic service discovery using nmap.

## Security Takeaway

A system can expose information through DNS, HTTP, and network services.

From a defensive perspective, unnecessary services should not be exposed, server information should be minimized
where practical, and network access should follow least-privilege principles.
